# Plan (milestones)

1. **Setup** — `python tasks.py start` (data, tests, first run, charts, report, progress in one go).
2. **Understand** — read docs/PROBLEM.md; solve a tiny instance by hand.
3. **Model & evaluator** — data structures + a function that checks validity and scores a solution, with tests.
4. **Baseline** — simplest correct algorithm; it is the bar to beat.
5. **Main algorithms** — the techniques required in docs/REQUIREMENTS.md, each wrapped with `Meter`.
6. **Reduction & tuning** — pruning / bounds / heuristics; record effect in DECISIONS.md.
7. **Experiments** — all sizes, several seeds, `python tasks.py plots`.
8. **Report** — fill README sections; `python tasks.py check` must show 100%.
9. **Defense** — be able to explain every algorithm, complexity and decision.
